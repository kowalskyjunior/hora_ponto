Usar o HourKWO no celular

O HourKWO funciona como PWA. Para sincronizar dados do PontoMais no celular sem depender de extensão do Chrome, use o bookmarklet abaixo no navegador que estiver usando.

1. Instale o HourKWO

Abra a página principal do HourKWO e use Adicionar à tela de início / Instalar app.

2. Crie o favorito “Enviar para HourKWO”

Crie um favorito nesta página e edite o endereço dele para o código abaixo. No iPhone, salve primeiro a página como favorito e depois edite o URL; no Android, o mesmo princípio vale em navegadores que aceitem bookmarklets.

javascript:(()=>{const t=document.body?.innerText||"";const a=[...t.matchAll(/\b([01]?\d|2[0-3]):([0-5]\d)\b/g)].map(m=>m[0]).filter((v,i,x)=>x.indexOf(v)===i);const u="https://kowalskyjunior.github.io/hora_ponto/";if(!a.length){alert("Nenhum horário encontrado na página do PontoMais.");return}location.href=u+"?times="+encodeURIComponent(a.join(","))+"&source=mobile";})()

3. Use

Abra o PontoMais, entre na tela que mostra suas marcações e execute o favorito Enviar para HourKWO.
O HourKWO recebe os horários encontrados, preenche a entrada e exibe as marcações capturadas.
